# מסע החשיבה

משחק חשיבה אינטראקטיבי בעברית לילדי כיתה ב', שמכין למבחני איתור המחוננים (שלב א' ושלב ב').

- 12 סוגי שאלות: אנלוגיות מילים, מילה לא שייכת, הבנת הנקרא, חשיבה לוגית, בעיות מילוליות, משוואות וסמלים, סדרות מספרים, סדרות צורות, מטריצות, אנלוגיות צורות, צורה יוצאת דופן ותמונת מראה.
- הקושי מותאם לכל נושא בנפרד (רמות 1 עד 5). אורך המשימה היומית נקבע לפי הזמן שיש ביום ולפי קצב התשובות בפועל.
- הילד או הילדה בוחרים עולם ודמות, אוספים כוכבים ופריטים לאוסף, ושומרים על רצף ימים.
- באזור ההורים יש מעקב לפי נושא, הגדרות, והקראה של השאלות בעברית לפי בחירה.

המשחק הוא קובץ HTML אחד (`index.html`), בלי שלב בנייה.

## התחברות עם Google ושמירת התקדמות (Firebase)

בלי הגדרה, המשחק עובד מיד, וההתקדמות נשמרת רק במכשיר שבו משחקים.
כדי שלכל משתמש תהיה התקדמות משלו שעוברת בין מכשירים, מחברים פרויקט Firebase חינמי:

1. נכנסים ל-https://console.firebase.google.com ויוצרים פרויקט חדש (אפשר לוותר על Google Analytics).
2. **Authentication** ← Get started ← Sign-in method ← מפעילים את **Google**.
3. **Authentication** ← Settings ← Authorized domains ← מוסיפים את `<שם-המשתמש>.github.io`.
4. **Firestore Database** ← Create database ← מצב Production ← בוחרים אזור (למשל `europe-west`).
5. **Firestore** ← Rules ← מדביקים את התוכן של `firestore.rules` מהמאגר הזה ← Publish.
6. **Project settings** (גלגל השיניים) ← Your apps ← מוסיפים אפליקציית Web (`</>`) ← מעתיקים את ה-`firebaseConfig`.
7. מדביקים את הערכים בקובץ `firebase-config.js` במקום `null`, ושומרים (commit).

ערכי ה-`firebaseConfig` לא סודיים, ומותר שיופיעו במאגר ציבורי. מה שמגן על הנתונים הם כללי האבטחה בקובץ `firestore.rules`: כל משתמש יכול לקרוא ולכתוב רק את ההתקדמות של עצמו.

## פרסום ב-GitHub Pages

Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main`, תיקייה `/ (root)` ← Save.
אחרי דקה או שתיים המשחק זמין בכתובת `https://<שם-המשתמש>.github.io/daria-excellence-trainer/`.
כל שינוי שנדחף ל-`main` מתפרסם אוטומטית, וכל מי שפותח את הקישור רואה תמיד את הגרסה האחרונה.

## באייפון ובאייפד

- כדי שיהיה אייקון כמו של אפליקציה: ב-Safari לוחצים על כפתור השיתוף ובוחרים **הוספה למסך הבית**.
- איכות ההקראה תלויה בקול שמותקן במכשיר. כדי לשפר: הגדרות ← נגישות ← תוכן מוקרא ← קולות ← עברית ← מורידים קול "משופר". אחר כך בוחרים אותו באזור ההורים במשחק.
